# UniversityCAD

**UniversityCAD** — это учебная 2D САПР (CAD) система, разработанная на C++ с использованием фреймворка Qt 6. Приложение реализует полноценный функционал для создания и редактирования геометрических примитивов с поддержкой привязок и стилей линий по ГОСТ 2.303-68.

## 🚀 Возможности

### Геометрические примитивы
- **Отрезок (Segment)** — линия между двумя точками
- **Окружность (Circle)** — построение по центру и радиусу, центру и диаметру, 2 точкам или 3 точкам
- **Дуга (Arc)** — построение по центру и углам или по 3 точкам
- **Прямоугольник (Rectangle)** — построение по 2 точкам, точке и размерам, или центру и размерам, с опциональным скруглением углов
- **Эллипс (Ellipse)** — построение по центру и радиусам или центру и 2 точкам на осях
- **Многоугольник (Polygon)** — правильный многоугольник (вписанный или описанный) с настраиваемым числом сторон
- **Сплайн (Spline)** — кривая через произвольное число контрольных точек

### Интерактивный 2D-вьюпорт
- Панорамирование (средняя кнопка мыши)
- Масштабирование (колесо мыши) с привязкой к курсору
- Поворот вида на 90° влево/вправо с анимацией
- Выделение объектов кликом или рамкой
- Динамическая координатная сетка с автомасштабированием
- Отображение гизмо осей координат

### Система привязок (Snap)
- **Endpoint** — привязка к конечным точкам
- **Midpoint** — привязка к середине
- **Center** — привязка к центру (окружности, дуги, многоугольника)
- **Quadrant** — привязка к квадрантам окружности (0°, 90°, 180°, 270°)
- **Intersection** — привязка к пересечениям объектов
- **Perpendicular** — привязка к перпендикуляру
- **Tangent** — привязка к касательной
- **Nearest** — привязка к ближайшей точке на объекте
- **Grid** — привязка к сетке

### Стили линий по ГОСТ 2.303-68
- Сплошная основная (толстая)
- Сплошная тонкая
- Сплошная волнистая
- Сплошная с изломами
- Штриховая
- Штрихпунктирная тонкая
- Штрихпунктирная утолщенная
- Штрихпунктирная с двумя точками
- Пользовательские стили

### Системы координат
- **Декартова** — ввод координат X, Y
- **Полярная** — ввод радиуса и угла (в градусах или радианах)

### Управление объектами
- Список всех объектов сцены с возможностью выбора
- Редактирование геометрии и стиля выбранных объектов
- Удаление объектов
- Панель свойств для просмотра и редактирования параметров

### Интерфейс
- Современная тёмная тема в стиле неон (QSS)
- Контекстное меню с быстрым доступом к функциям
- Кнопки инструментов с поддержкой долгого нажатия для выбора метода построения

## 🛠️ Технологии
- **C++ 17** — язык программирования
- **Qt 6** — кроссплатформенный UI-фреймворк
- **CMake** — система сборки

## ⚙️ Сборка и запуск

Для сборки проекта необходимы: компилятор C++17, CMake 3.16+ и Qt 6.

1. **Клонируйте репозиторий:**
   ```sh
   git clone https://github.com/Hemaxa/UniversityCAD.git
   cd UniversityCAD
   ```

2. **Создайте директорию для сборки:**
   ```sh
   mkdir build && cd build
   ```

3. **Сконфигурируйте проект с CMake:**
   ```sh
   cmake .. -DCMAKE_PREFIX_PATH=/путь/к/вашему/Qt6
   ```
   Если Qt 6 установлен в стандартную директорию:
   ```sh
   cmake ..
   ```

4. **Скомпилируйте проект:**
   ```sh
   cmake --build . -j$(nproc)
   ```

5. **Запустите приложение:**
   ```sh
   ./UniversityCAD
   ```
