# UniversityCAD

**UniversityCAD** — это учебная 2D САПР (CAD) система, разработанная на C++ с использованием фреймворка Qt 6. Приложение реализует функционал для создания и редактирования геометрических примитивов, объектных привязок, стилей линий по ГОСТ 2.303-68 и ассоциативных размеров по логике ЕСКД/ГОСТ 2.307-2011.

## 🚀 Возможности

### Геометрические примитивы
- **Отрезок (Segment)** — линия между двумя точками
- **Окружность (Circle)** — построение по центру и радиусу, центру и диаметру, 2 точкам или 3 точкам
- **Дуга (Arc)** — построение по центру и углам или по 3 точкам
- **Прямоугольник (Rectangle)** — построение по 2 точкам, точке и размерам, или центру и размерам, с опциональным скруглением углов
- **Эллипс (Ellipse)** — построение по центру и радиусам или центру и 2 точкам на осях
- **Многоугольник (Polygon)** — правильный многоугольник (вписанный или описанный) с настраиваемым числом сторон
- **Сплайн (Spline)** — кривая через произвольное число контрольных точек
- **Точка (Point)** — отдельный точечный объект для построений и привязок

### Размеры по ЕСКД
- **Линейные размеры** — выровненный, горизонтальный и вертикальный размер
- **Радиальные размеры** — радиус окружности, дуги, эллипса и подходящих концентрических объектов
- **Диаметральные размеры** — диаметр окружности, дуги и осей эллипса
- **Угловые размеры** — размер угла между гранями или угла дуги
- **Ассоциативность** — размеры связываются с примитивами и автоматически пересчитываются при изменении геометрии
- **Обратное редактирование** — изменение значения размера может перестраивать связанный примитив: сторону прямоугольника, длину отрезка, радиус окружности/дуги, радиусы эллипса, угол дуги, радиус правильного многоугольника
- **Гриповое редактирование** — выбранный размер можно перемещать за управляющие точки: точки привязки, положение размерной линии и позицию текста
- **Ручной текст размера** — двойной клик по размерному тексту позволяет задать новое значение или переопределить подпись
- **Положение текста** — текст прикреплён к размерной линии и перемещается вдоль неё; доступно центрирование текста
- **Стрелки** — закрытая, открытая, засечка и точка, с настройкой размера, заполнения и положения внутри/снаружи

### Интерактивный 2D-вьюпорт
- Панорамирование (средняя кнопка мыши)
- Масштабирование (колесо мыши) с привязкой к курсору
- Поворот вида на 90° влево/вправо с анимацией
- Выделение объектов кликом или рамкой, включая размеры
- Множественное выделение: `Shift` добавляет объекты к выбору, `Ctrl` удаляет из выбора
- Удаление выбранных объектов клавишами `Delete` или `Backspace`
- Динамическая координатная сетка с автомасштабированием
- Отображение гизмо осей координат

### Система привязок (Snap)
- **Endpoint** — привязка к конечным точкам
- **Midpoint** — привязка к середине
- **Center** — привязка к центру (окружности, дуги, многоугольника)
- **Quadrant** — привязка к квадрантам окружности (0°, 90°, 180°, 270°)
- **Intersection** — привязка к пересечениям объектов
- **Perpendicular** — привязка к перпендикуляру
- **Tangent** — привязка к касательной
- **Nearest** — привязка к ближайшей точке на объекте
- **Grid** — привязка к сетке

### Стили линий по ГОСТ 2.303-68
- Сплошная основная (толстая)
- Сплошная тонкая
- Сплошная волнистая
- Сплошная с изломами
- Штриховая
- Штрихпунктирная тонкая
- Штрихпунктирная утолщенная
- Штрихпунктирная с двумя точками
- Пользовательские стили

### Настройки размеров
- Отдельное меню **«Настройки размеров»** для глобального стиля всех размеров
- Настройка цвета выносных линий, размерной линии и текста
- Настройка типов линий для выносных и размерных линий
- Настройка выхода выносных линий и продолжения размерной линии
- Настройка стрелок: тип, размер, заполнение и расположение
- Настройка текста: шрифт, высота, отступ от размерной линии
- Применение глобальных настроек к уже созданным размерам при закрытии меню
- Индивидуальные параметры выбранного размера доступны в панели свойств объекта

### Системы координат
- **Декартова** — ввод координат X, Y
- **Полярная** — ввод радиуса и угла (в градусах или радианах)

### Управление объектами
- Список всех объектов сцены с возможностью выбора
- Редактирование геометрии и стиля выбранных объектов
- Удаление объектов и размеров
- Панель свойств для просмотра и редактирования параметров
- Переключение допустимых способов построения без сброса текущей геометрии объекта
- Контекстное меню с инструментами построения примитивов и размеров

### Экспорт и Импорт
- **DXF (AutoCAD 2000 / AC1015)** — полноценное чтение и запись чертежей в формате DXF
- Точное сохранение всех примитивов (сплайны, блоки, полилинии, дуги) с цветами и весами линий
- Поддержка собственных (native) пользовательских типов линий (сплошная волнистая, зигзаг) через XData для идеального восстановления ваших чертежей
- Корректная обработка направления осей и углов для совместимости с любыми САПР (T-Flex, AutoCAD и др.)
- Экспорт размеров в DXF:
  - внутренние данные `UNIVERSITYCAD_DIM` сохраняют параметры и ассоциативность при обратном импорте в UniversityCAD;
  - видимая геометрия размеров экспортируется обычными сущностями `LINE`, `ARC`, `CIRCLE` и `TEXT`, чтобы размеры отображались во внешних CAD-системах, включая T-FLEX;
  - вспомогательная геометрия размеров помечается как `UNIVERSITYCAD_DIM_GEOM` и не дублируется при повторном импорте в UniversityCAD

### Интерфейс
- Современная тёмная тема в стиле неон (QSS)
- Контекстное меню с быстрым доступом к функциям
- Кнопки инструментов с поддержкой долгого нажатия для выбора метода построения

## ⚙️ Сборка и запуск

Для сборки проекта необходимы: компилятор C++17, CMake 3.16+ и Qt 6.

1. **Клонируйте репозиторий:**
   ```sh
   git clone https://github.com/Hemaxa/UniversityCAD.git
   cd UniversityCAD
   ```

2. **Создайте директорию для сборки:**
   ```sh
   mkdir build && cd build
   ```

3. **Сконфигурируйте проект с CMake:**
   Если вы используете систему, где Qt установлен в стандартные пути (например, Linux или Homebrew):
   ```sh
   cmake ..
   ```
   В противном случае (если Qt скачан через установщик), укажите путь (замените на свой вариант):
   ```sh
   cmake .. -DCMAKE_PREFIX_PATH=~/Qt/6.x.x/macos
   ```

4. **Скомпилируйте проект:**
   Используем кросс-платформенный ключ `--parallel` для сборки на всех ядрах процессора:
   ```sh
   cmake --build . --parallel
   ```

5. **Запустите приложение (находясь в папке build):**
   ```sh
   ./UniversityCAD
   ```
   *(Если вы используете Xcode-генератор CMake на macOS, приложение может находиться в папке `Debug/UniversityCAD` или быть собрано как `.app` файл — в таком случае открывайте с помощью `open UniversityCAD.app`)*
